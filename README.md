## 🎮 About the Game
DoubleVision is a reflex-based minigame where you must identify matching images between two "eyes" on the screen.

### Features
- **Two Difficulty Modes**:
  - **Easy**: 3 images per eye. Perfect for warming up.
  - **Hard**: 5 images per eye. For the true perfectionists.
- **Dynamic Audio**:
  - Retro-style sound effects for matches and mismatches.
  - Atmospheric background music (`puzzles.ogg`).
  - **Mute Control**: Easily toggle audio on/off with the in-game speaker button.
- **Scoring System**: Earn points for every match. Be careful—mismatches will cost you points!
- **Timer Challenge**: Get the highest score possible before the 60-second timer runs out.
- **Responsive Animations**: Smooth eye movements and feedback animations.

## 🕹️ How to Play
1. **Start**: Click anywhere on the home screen to begin.
2. **Choose Level**: Select between "Easy" or "Hard" mode.
3. **Match**: Find the one image that appears in BOTH eyes. Click it as fast as you can!
4. **Score**: 
   - **Correct Match**: +10 points.
   - **Mismatch**: -10 points.
   - **Lose Condition**: If your score drops below -30, the game ends early.

## 🛠️ Technologies Used
- **HTML5**: Semanti structure and game layout.
- **CSS3**: Custom animations (keyframes, transitions) and responsive design.
- **JavaScript (Vanilla)**: Game logic, state management, and audio integration.
- **Bootstrap 5**: Used for layout components.

## 📁 Project Structure
- `index.html`: Main game entry point.
- `assets/css/style.css`: All game styles and eye-pupil animations.
- `assets/js/code.js`: Core game logic and audio handling.
- `assets/images/`: Game icons and UI assets.
- `assets/sounds/`: Background music and sound effects.
